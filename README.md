# 🛍️ Pasarela E-Commerce Wompi Bancolombia

Solución técnica integral de comercio electrónico y pasarela de pagos con tarjeta de crédito tokenizada, desarrollada bajo **Arquitectura Hexagonal (Puertos y Adaptadores)**, **Programación Orientada a Ferrocarriles (Railway Oriented Programming - ROP)**, **NestJS**, **PostgreSQL**, **React 19**, **Redux Toolkit**, **Tailwind CSS** y la especificación de diseño **Material Design Backdrop**.

## 🚀 Inicio Rápido

### 1. Iniciar Backend
```bash
cd backend
npm install
npm run start:dev
```
API activa en `http://localhost:3000/api` | Swagger en `http://localhost:3000/api/docs`.

### 2. Iniciar Frontend
```bash
cd frontend
npm install
npm run dev
```
Aplicación activa en `http://localhost:5173`.
